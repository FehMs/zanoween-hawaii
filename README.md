# Zanoween — Hawaii Edition

Landing page estática em português, responsiva e sem dependências de build.

Abra `dist/index.html` ou sirva `dist` com um servidor HTTP local. Para publicar, use o manifesto `.openai/hosting.json`.

## Informações confirmadas

- Data no guia: 12/12/2026.
- Local informado: Espaço Limão.
- Endereço completo revelado após a compra.
- Horário e link de ingressos ainda não fornecidos. O botão abre um aviso honesto de vendas em breve e permite baixar um evento de dia inteiro para a agenda.

## Identidade visual

Paleta baseada no guia: creme, laranja, preto, marrom e rosa. As fontes Shrikhand, Barlow Condensed e DM Sans são alternativas servidas pelo Google Fonts; os arquivos originais de Kahlua, Montserrat e os logos não estavam disponíveis na pasta. Wordmarks compostos em texto.

Arte criada com a ferramenta integrada ImageGen, salva em `dist/assets/tropical-night.png`.
